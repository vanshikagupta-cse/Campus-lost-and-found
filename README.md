# 🎒 Campus Lost and Found Portal

A campus portal application designed to help college students report, track, and recover lost or found items across campus.

---
## ✨ Key Features
- 🔍 Report Lost Items: Structured form interface for students to log details of misplaced belongings (item name, description, last seen location, and contact info).
- 📦 Report Found Items: Dedicated section to list found items so owners can verify and claim them.
- ⚙️ Core Logic and Data Handling: Java-based logic to manage item records, search queries, and status tracking.
- 🎨 Clean Web Interface: User-friendly frontend pages built with HTML and CSS for smooth navigation.

---
## 🛠️ Technologies Used
- 🌐 Frontend: HTML5, CSS3
- ☕ Backend / Core Logic: Java

---
## 🚀 How to Run
1. Download or clone this repository to your computer.
2. Frontend: Open the main .html file in any web browser (Chrome, Edge, etc.) to view the portal interface.
3. Java Files: Open the .java files in VS Code or any Java IDE (IntelliJ / Eclipse), compile, and run the main class.
